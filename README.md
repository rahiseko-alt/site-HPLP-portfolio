# 空間工房 コーポレートサイト

ホームページ制作の商品サンプル（ポートフォリオ）です。
架空の内装会社「株式会社 空間工房」のコーポレートサイトを制作しました。

## 公開ページ

https://muse.ai/s/kong-jian-gong-fang-hp-gong-kai-ban-bxs6xlxixqxgxb5xzr/CZouWNO_o2DSlETZLd0YCGHFZXtQ3kxhvvjzlkLI-gw

## 内容

- 構成：ヒーロー、導入文、サービス3件（住宅リノベーション／水回り・部分改修／店舗・オフィス内装）、施工事例3件、工事の流れ3ステップ、お知らせ3件、会社情報、採用、お問い合わせ、フッター
- レスポンシブデザイン対応（スマートフォン・タブレット・PC）

## 特徴

- 管理画面つき：ページ内のほぼ全ての文字を、管理画面のフォームから変更できます（本文テキスト約70項目、施工事例、工事の流れ、お知らせ、サービス、基本情報）。レイアウトや色は変わりません
- SEO内部対策：title・meta descriptionの固有化、OGP、見出し階層、画像の代替テキスト、会社情報の構造化データ（JSON-LD）を、対策リストと照合して実装済みです

## 公開版についての注意

- 上記の公開ページは確認用の版です。管理画面で変更した内容はその場で画面に反映されますが、保存はされません（開き直すと初期の内容に戻ります）。納品版では、変更内容がサーバー側に保存されます
- 会社名・住所・実績は全て架空のものです
